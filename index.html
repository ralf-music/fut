Hinweis

Lokale Datenspeicherung

Alle Daten werden ausschließlich lokal in diesem Browser auf diesem Gerät gespeichert. Es werden keine Daten an einen Server übertragen.

  • Gespeichert werden Favoriten, Verlauf, Notizen und Eingaben.
  • Beim Löschen der Browserdaten oder des Website-Speichers gehen diese Daten verloren.
  • Die installierte PWA kann offline genutzt werden.
